# Página institucional FAGOO

Fonte estática preparada para o endereço institucional do projeto. Nenhum domínio, publicação ou recurso remoto é criado pelo comando de build.

```sh
npm run build --workspace @fagoo/site
```

O resultado em `dist/` contém HTML, CSS e um ícone SVG. O site não usa formulários de coleta, cookies analíticos ou bibliotecas externas em tempo de execução.

`wrangler.jsonc` contém a configuração básica para uma futura publicação explicitamente solicitada. O domínio deve ser associado no ambiente de destino; nenhum identificador de conta real pertence a este arquivo.

Os links de instalação apontam à documentação do repositório. Disponibilidade fiscal, perfis bancários, aplicativos e homologação são apresentados com suas condições, sem promessas de recursos ainda não liberados.
